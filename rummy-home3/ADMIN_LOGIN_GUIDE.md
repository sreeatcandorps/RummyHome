# Admin Login Guide

## 🔐 **How to Login as Admin**

### **Method 1: From Login Screen (Recommended)**
1. **Open the app** and go to the login screen
2. **Look for the "🔐 Admin Access" button** at the bottom
3. **Tap the button** to go to the admin login screen
4. **Tap "Login as Admin"** to create and login as admin
5. **You'll be redirected** to the main app with admin privileges

### **Method 2: From Settings Screen**
1. **Login normally** with any account
2. **Go to Settings** (gear icon in bottom tab)
3. **Scroll down** to find "Restore Admin Account" button
4. **Tap the button** to create admin account
5. **Restart the app** when prompted

## 🚀 **Quick Start**

### **First Time Setup:**
1. Open the app
2. Tap "🔐 Admin Access" on login screen
3. Tap "Login as Admin"
4. You're now logged in as admin!

### **Subsequent Logins:**
- If you've used admin before, you can:
  - Use the "🔐 Admin Access" button again, OR
  - Use the "Restore Admin Account" button in Settings

## 🛡️ **Security Notes**

### **Local Only:**

- Not shared with other users
- Safe for development and testing

### **No Password Required:**
- Admin login is instant
- No authentication needed

## 🔄 **Switching Between Accounts**

### **From Admin to Regular User:**
1. Go to **Settings**
2. Tap **"Sign Out"**
3. Login with a regular account

### **From Regular User to Admin:**
1. Go to **Settings**
2. Tap **"Restore Admin Account"**
3. Restart the app when prompted

## 🚨 **Troubleshooting**

### **Admin Login Not Working:**
1. **Check if you're already logged in** - sign out first
2. **Try the Settings method** - "Restore Admin Account"
3. **Restart the app** after creating admin account
4. **Clear app data** if needed (will remove all data)

### **Admin Features Not Showing:**
1. **Verify you're logged in as admin** - check profile
2. **Look for admin sections** in Settings
3. **Check if admin role is set** correctly
4. **Restart the app** to refresh permissions

### **Can't Switch Back to Regular User:**
1. **Sign out** from Settings
2. **Login with regular account**
3. **Or register a new account**
4. **Admin account remains available** for future use
