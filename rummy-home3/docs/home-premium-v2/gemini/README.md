# EZ Score: Rummy — Home Screen Luxury Themes (Gemini)

All directions keep D136's exact Home layout and D137's two-button bottom bar (`Home` + profile initials) so every theme works as a clean switch in Profile › Appearance (only colors, surface materials, and subtle hero header ornament change). Every screen is rendered from real HTML/CSS/SVG using the app's MaterialCommunityIcons and passes an automated check for zero clipped text and ≥ 4.5:1 text contrast (actual minimum across all renders: 5.29:1). In Round 2, generated textures appear strictly behind the top hero header—never behind cards, buttons, or body text.
